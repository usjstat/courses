Course outline

The course develops Bayesian statistical modelling through computation, with primary emphasis on R and selected comparisons using Python/PyMC.

The main reference is Bayes Rules! An Introduction to Applied Bayesian Modeling, supported by selected material from Bayesian Modeling and Computation in Python.

Main topics

  • Bayesian probability and statistical reasoning
  • Prior distributions and likelihood construction
  • Posterior distributions and posterior summaries
  • Posterior simulation and Monte Carlo methods
  • Markov chain Monte Carlo
  • Bayesian regression
  • Generalized Bayesian models
  • Hierarchical models
  • MCMC diagnostics
  • Posterior predictive checking
  • Model comparison and predictive assessment
  • Bayesian workflow for Data Science

Software

The main computing environment is R.

Recommended packages include:

library(tidyverse)
library(bayesrules)
library(rstanarm)
library(cmdstanr)
library(posterior)
library(bayesplot)
library(tidybayes)
