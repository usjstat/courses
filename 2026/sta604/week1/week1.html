1 Block 1 — Thinking like a Bayesian

1.1 1.1 What problem is Bayesian statistics solving?

Suppose we want to learn an unknown population quantity:

  • the probability that a customer churns,
  • the conversion rate of a web page,
  • the average treatment effect,
  • the scoring probability of a player,
  • a regression coefficient,
  • the expected number of claims,
  • the probability that a classifier is correct.

Call the unknown quantity \(\theta\).

In a Bayesian analysis, uncertainty about \(\theta\) is represented using a probability distribution.

Before observing the current data, uncertainty about \(\theta\) is represented by a prior density or probability mass function

\[ f(\theta). \]

This is the prior distribution.

After observing data \(y\), uncertainty is updated and represented by

\[ f(\theta\mid y). \]

This is the posterior distribution.

The data connect to the parameter through the sampling distribution or likelihood contribution

\[ f(y\mid\theta). \]

The Bayesian workflow begins with three objects:

\[ \boxed{\text{prior} + \text{sampling model/data} \longrightarrow \text{posterior}} \]

Later in the course we will add posterior computation, diagnostics, prediction, model checking, and model comparison.

1.2 1.2 Bayesian probability

At undergraduate level, probability is often introduced as a long-run relative frequency. That interpretation is useful, but Bayesian inference also uses probability to quantify uncertainty.

Examples:

\[ \Pr(\theta > 0.5\mid y)=0.92 \]

means that, conditional on the model and observed data, 92% of the posterior probability lies above 0.5.

This is different from saying that 92% of repeated estimates would exceed 0.5.

The object \(\theta\) is unknown. In Bayesian analysis, our uncertainty about it is represented probabilistically.

ImportantParameter versus data

Before observing the data, both the data \(Y\) and the parameter \(\theta\) can be treated probabilistically in the Bayesian model.

After observing \(Y=y\), the observed data value is fixed. Uncertainty remains in \(\theta\).

1.3 1.3 Refresher: conditional probability

For events \(A\) and \(B\),

\[ \Pr(A\mid B)=\frac{\Pr(A\cap B)}{\Pr(B)}, \qquad \Pr(B)>0. \]

Similarly,

\[ \Pr(B\mid A)=\frac{\Pr(A\cap B)}{\Pr(A)}. \]

Therefore,

\[ \Pr(A\cap B)=\Pr(A\mid B)\Pr(B)=\Pr(B\mid A)\Pr(A). \]

This gives Bayes’ rule:

\[ \boxed{ \Pr(A\mid B) = \frac{\Pr(B\mid A)\Pr(A)}{\Pr(B)} } \]

If \(A_1,\ldots,A_k\) form a partition,

\[ \Pr(B)=\sum_{j=1}^{k}\Pr(B\mid A_j)\Pr(A_j). \]

This denominator is the marginal probability or normalizing constant.

1.4 1.4 Why reversing a conditional probability is dangerous

A common error is to treat

\[ \Pr(A\mid B) \]

as though it were

\[ \Pr(B\mid A). \]

They are generally different.

For example:

  • \(\Pr(\text{positive test}\mid\text{disease})\) is sensitivity.
  • \(\Pr(\text{disease}\mid\text{positive test})\) is the probability a person has the disease after a positive test.

The second depends not only on sensitivity but also on disease prevalence and false-positive probability.

1.5 1.5 Random variables, distributions and parameters

A random variable maps outcomes to numerical values.

A probability distribution describes the possible values of a random variable and their probabilities or densities.

Examples:

\[ Y\sim\text{Binomial}(n,\pi) \]

\[ Y\sim\text{Poisson}(\lambda) \]

\[ Y\sim N(\mu,\sigma^2) \]

The symbols \(\pi,\lambda,\mu,\sigma\) are parameters.

In classical inference, parameters are usually treated as fixed unknown constants.

In Bayesian inference, we assign probability models to unknown parameters:

\[ \pi\sim\text{Beta}(\alpha,\beta), \]

or

\[ \mu\sim N(m_0,s_0^2). \]

The parameter is still an unknown scientific quantity. The probability distribution expresses our uncertainty about it.

1.6 1.6 Prior information is not necessarily personal opinion

A prior can be informed by:

  • previous studies,
  • historical data,
  • physical constraints,
  • expert elicitation,
  • earlier seasons or cohorts,
  • engineering tolerances,
  • substantive theory,
  • weakly informative regularization,
  • deliberately broad uncertainty.

A prior should be interpretable in the context of the model.

A Bayesian analysis is not made better merely by choosing a vague prior. A poorly chosen vague prior can imply implausible values.

2 Block 2 — Bayes’ rule as learning from evidence

2.1 2.1 The discrete Bayes formula

Suppose the unknown state is one of

\[ \theta_1,\theta_2,\ldots,\theta_k. \]

Before observing data \(y\), assign prior probabilities

\[ \Pr(\theta_j). \]

The data model gives

\[ \Pr(y\mid\theta_j). \]

Then

\[ \Pr(\theta_j\mid y) = \frac{\Pr(y\mid\theta_j)\Pr(\theta_j)} {\sum_{\ell=1}^{k}\Pr(y\mid\theta_\ell)\Pr(\theta_\ell)}. \]

Notice the structure:

\[ \text{posterior} = \frac{\text{likelihood}\times\text{prior}} {\text{evidence}}. \]

2.2 2.2 Worked example: fraud screening

Suppose:

\[ \Pr(F)=0.01 \]

where \(F\) means that a transaction is fraudulent.

A screening model has

\[ \Pr(+\mid F)=0.95 \]

and

\[ \Pr(+\mid F^c)=0.04. \]

We want

\[ \Pr(F\mid +). \]

Bayes’ rule gives

\[ \Pr(F\mid +) = \frac{\Pr(+\mid F)\Pr(F)} {\Pr(+\mid F)\Pr(F)+\Pr(+\mid F^c)\Pr(F^c)}. \]

Substituting:

\[ \Pr(F\mid +) = \frac{0.95(0.01)} {0.95(0.01)+0.04(0.99)} \approx 0.1935. \]

So even after a positive flag, the posterior probability of fraud is only about 19.4%.

Why? Fraud is rare.

The low prior prevalence matters.

2.3 2.3 Prior odds, likelihood ratio, posterior odds

Bayes’ rule can also be written in odds form:

\[ \boxed{ \text{Posterior odds} = \text{Prior odds} \times \text{Likelihood ratio} } \]

For the fraud example,

\[ \text{Prior odds} = \frac{0.01}{0.99}, \]

and the positive likelihood ratio is

\[ LR_+ = \frac{\Pr(+\mid F)}{\Pr(+\mid F^c)} = \frac{0.95}{0.04} = 23.75. \]

Therefore,

\[ \text{Posterior odds} = \frac{0.01}{0.99}\times23.75. \]

This representation is especially useful when evidence arrives sequentially.

2.5 2.5 From events to parameters

The same logic applies when the unknown object is a numerical parameter \(\theta\).

For a continuous parameter,

\[ \boxed{ f(\theta\mid y) = \frac{f(y\mid\theta)f(\theta)} {f(y)} } \]

where

\[ f(y) = \int f(y\mid\theta)f(\theta)\,d\theta. \]

In most Bayesian modelling, we use the proportional form

\[ \boxed{ f(\theta\mid y) \propto f(y\mid\theta)f(\theta) } \]

because \(f(y)\) does not depend on \(\theta\).

This is the key equation for the entire course.

2.6 2.6 Sampling distribution versus likelihood

Suppose

\[ Y\mid\pi\sim\text{Binomial}(n,\pi). \]

The sampling probability mass function is

\[ f(y\mid\pi) = {n\choose y}\pi^y(1-\pi)^{n-y}. \]

Before data are observed, this is a function of possible values \(y\).

After observing \(Y=y\), the likelihood treats \(y\) as fixed and views the same expression as a function of \(\pi\):

\[ L(\pi\mid y) = {n\choose y}\pi^y(1-\pi)^{n-y}. \]

For inference about \(\pi\),

\[ L(\pi\mid y) \propto \pi^y(1-\pi)^{n-y}. \]

The likelihood is not a probability distribution for \(\pi\). It does not have to integrate to one over \(\pi\).

3 Block 3 — The Beta-Binomial model

3.1 3.1 Why use a Beta prior for a probability?

For a probability parameter,

\[ 0<\pi<1. \]

The Beta distribution has support on this interval:

\[ \pi\sim\text{Beta}(\alpha,\beta), \qquad \alpha>0,\;\beta>0. \]

Its density is

\[ f(\pi) = \frac{\Gamma(\alpha+\beta)} {\Gamma(\alpha)\Gamma(\beta)} \pi^{\alpha-1}(1-\pi)^{\beta-1}. \]

The mean is

\[ E(\pi)=\frac{\alpha}{\alpha+\beta}. \]

The variance is

\[ \operatorname{Var}(\pi) = \frac{\alpha\beta} {(\alpha+\beta)^2(\alpha+\beta+1)}. \]

When \(\alpha>1\) and \(\beta>1\), the mode is

\[ \operatorname{Mode}(\pi) = \frac{\alpha-1}{\alpha+\beta-2}. \]

The sum

\[ \alpha+\beta \]

is often interpreted informally as a measure of prior concentration or prior information strength.

3.2 3.2 Reading Beta distributions

Consider:

\[ \text{Beta}(1,1),\quad \text{Beta}(2,2),\quad \text{Beta}(8,2),\quad \text{Beta}(20,20). \]

Their means are:

\[ 0.5,\quad0.5,\quad0.8,\quad0.5. \]

But they express very different uncertainty.

A prior mean alone is not enough.

3.3 3.3 Constructing the Beta-Binomial model

Let

\[ Y\mid\pi\sim\text{Binomial}(n,\pi) \]

and

\[ \pi\sim\text{Beta}(\alpha,\beta). \]

The likelihood is

\[ L(\pi\mid y) \propto \pi^y(1-\pi)^{n-y}. \]

The prior is

\[ f(\pi) \propto \pi^{\alpha-1}(1-\pi)^{\beta-1}. \]

Therefore,

\[ f(\pi\mid y) \propto f(\pi)L(\pi\mid y) \]

\[ \propto \pi^{\alpha-1}(1-\pi)^{\beta-1} \pi^y(1-\pi)^{n-y} \]

\[ = \pi^{\alpha+y-1} (1-\pi)^{\beta+n-y-1}. \]

Recognize the kernel of a Beta distribution:

\[ \boxed{ \pi\mid y \sim \text{Beta} (\alpha+y,\;\beta+n-y) } \]

This is called conjugacy.

The Beta prior is conjugate to the Binomial likelihood because the posterior is also Beta.

3.4 3.4 Interpreting the update

The update can be written:

\[ \alpha_{\text{post}}=\alpha+y, \]

\[ \beta_{\text{post}}=\beta+n-y. \]

So successes add to \(\alpha\), and failures add to \(\beta\).

This gives the Beta parameters a useful pseudo-count interpretation, although the interpretation must be used carefully when \(\alpha,\beta\) are not integers or when the prior was not literally constructed from historical Binomial data.

3.5 3.5 Worked example

Suppose we model a conversion probability \(\pi\) using

\[ \pi\sim\text{Beta}(4,6). \]

The prior mean is

\[ E(\pi)=\frac{4}{10}=0.4. \]

Now observe 18 conversions among 30 users:

\[ Y=18,\qquad n=30. \]

The posterior is

\[ \pi\mid y \sim \text{Beta}(4+18,6+12) = \text{Beta}(22,18). \]

The posterior mean is

\[ E(\pi\mid y) = \frac{22}{40} = 0.55. \]

The sample proportion is

\[ \hat\pi=\frac{18}{30}=0.60. \]

So the posterior mean lies between the prior mean 0.40 and the observed proportion 0.60.

That is the Bayesian compromise.

3.6 3.6 Posterior mean as a weighted average

For the Beta-Binomial model,

\[ E(\pi\mid y) = \frac{\alpha+y}{\alpha+\beta+n}. \]

Rewrite it as

\[ E(\pi\mid y) = \frac{\alpha+\beta}{\alpha+\beta+n} \frac{\alpha}{\alpha+\beta} + \frac{n}{\alpha+\beta+n} \frac{y}{n}. \]

Therefore,

\[ \boxed{ E(\pi\mid y) = w_{\text{prior}}E(\pi) + w_{\text{data}}\hat{\pi} } \]

where

\[ w_{\text{prior}} = \frac{\alpha+\beta} {\alpha+\beta+n} \]

and

\[ w_{\text{data}} = \frac{n} {\alpha+\beta+n}. \]

The weights add to one.

This formula provides a direct mathematical explanation of the balance between prior information and data.

4 Block 4 — Bayesian computation begins

4.1 4.1 Why simulate when the posterior is known?

For the Beta-Binomial model, the posterior can be written analytically.

But simulation is still useful because it prepares us for models where analytic formulas are unavailable.

If

\[ \pi\mid y\sim\text{Beta}(22,18), \]

we can generate posterior draws:

\[ \pi^{(1)},\ldots,\pi^{(S)} \sim \text{Beta}(22,18). \]

Then posterior quantities can be estimated numerically.

For example,

\[ E(\pi\mid y) \approx \frac{1}{S} \sum_{s=1}^{S}\pi^{(s)}. \]

and

\[ \Pr(\pi>0.5\mid y) \approx \frac{1}{S} \sum_{s=1}^{S} I(\pi^{(s)}>0.5). \]

This is the basic Monte Carlo idea.

This is a probability statement about the unknown parameter within the Bayesian model.

4.5 4.5 Prior predictive thinking

Before seeing the current data, ask:

If my prior and sampling model were reasonable, what kinds of data would they generate?

Suppose

\[ \pi\sim\text{Beta}(4,6), \]

and

\[ Y\mid\pi\sim\text{Binomial}(30,\pi). \]

A prior predictive simulation is:

  1. draw \(\pi^{(s)}\) from the prior;
  2. draw \(Y^{(s)}\) from the Binomial model conditional on \(\pi^{(s)}\);
  3. inspect the distribution of simulated \(Y\).
  • R
  • Python
set.seed(604)

S <- 10000
pi_prior <- rbeta(S, 4, 6)
y_prior <- rbinom(S, size = 30, prob = pi_prior)

summary(y_prior)
quantile(y_prior, c(0.025, 0.5, 0.975))

hist(
  y_prior,
  breaks = seq(-0.5, 30.5, by = 1),
  main = "Prior predictive distribution",
  xlab = "Number of successes out of 30"
)
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(604)

S = 10000

This idea will become central later.

4.6 4.6 Prior influence and sample size

Consider the same observed rate \(y/n=0.70\), but with different sample sizes.

A Beta(8,12) prior has mean 0.40.

If:

\[ y=7,\;n=10, \]

the posterior is

\[ \text{Beta}(15,15) \]

with mean 0.50.

If:

\[ y=70,\;n=100, \]

the posterior is

\[ \text{Beta}(78,42) \]

with mean 0.65.

If:

\[ y=700,\;n=1000, \]

the posterior mean is very close to 0.70.

As the data accumulate, the original prior usually contributes a smaller proportion of total information.

4.7 4.7 Sequential Bayesian updating

Suppose

\[ \pi\sim\text{Beta}(2,3). \]

You observe data in stages.

4.7.1 Batch 1

3 successes and 2 failures:

\[ \pi\mid y_1 \sim \text{Beta}(2+3,3+2) = \text{Beta}(5,5). \]

4.7.2 Batch 2

Then observe 4 successes and 1 failure.

Use the first posterior as the next prior:

\[ \pi\mid y_1,y_2 \sim \text{Beta}(5+4,5+1) = \text{Beta}(9,6). \]

If we had combined the data immediately:

  • total successes \(=7\),
  • total failures \(=3\),

giving

\[ \text{Beta}(2+7,3+3) = \text{Beta}(9,6). \]

Same result.

This illustrates sequential coherence.

4.8 4.8 Sequential updating in code

  • R
  • Python
alpha <- 2
beta <- 3

# Batch 1: 3 successes, 2 failures
alpha <- alpha + 3
beta <- beta + 2

c(alpha, beta)

# Batch 2: 4 successes, 1 failure
alpha <- alpha + 4
beta <- beta + 1

c(alpha, beta)
alpha = 2
beta = 3

# Batch 1: 3 successes, 2 failures
alpha += 3
beta += 2

print(alpha, beta)

# Batch 2: 4 successes, 1 failure
alpha += 4
beta += 1

print(alpha, beta)

4.9 4.9 A first posterior decision statement

Suppose our decision threshold is:

\[ \pi>0.50. \]

Under a posterior \(\text{Beta}(22,18)\),

\[ \Pr(\pi>0.50\mid y) \]

may be directly relevant.

  • R
  • Python
1 - pbeta(0.50, 22, 18)
from scipy.stats import beta

1 - beta.cdf(0.50, 22, 18)

Bayesian analysis allows us to answer probability questions about parameters directly.

But a posterior probability is not automatically a decision rule. Decisions also require consequences, costs, benefits, or a loss function.

That distinction will matter later.

7 What you should retain from Week 1

The central identity is:

\[ \boxed{ f(\theta\mid y) \propto f(y\mid\theta)f(\theta) } \]

A Bayesian model has a logical sequence:

\[ \boxed{ \text{Question} \rightarrow \text{Parameter} \rightarrow \text{Prior} \rightarrow \text{Likelihood} \rightarrow \text{Posterior} \rightarrow \text{Posterior interpretation} } \]

For the Beta-Binomial model:

\[ \pi\sim\text{Beta}(\alpha,\beta), \]

\[ Y\mid\pi\sim\text{Binomial}(n,\pi), \]

\[ \boxed{ \pi\mid y \sim \text{Beta}(\alpha+y,\beta+n-y) } \]

and posterior simulation converts distributional questions into numerical summaries.
